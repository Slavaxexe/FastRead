# FastRead Native — две сборки

Нативное Android-приложение, minSdk 19. В обоих APK отсутствуют WebView, JavaScript, HTML и браузерный движок. Сборки устанавливаются рядом друг с другом и со старой 1.2; у каждой отдельная библиотека.

| APK | Пакет | Вывод |
| --- | --- | --- |
| FastRead-Native-Universal.apk | com.fastread.nativeapp | Нативный Canvas; без вызовов ONYX API |
| FastRead-Native-BOOX.apk | com.fastread.nativeapp.boox | Программный Canvas поля слова, чёрно-белые глифы по умолчанию; проверяемые команды A2 и полной очистки |

Поле имеет фиксированные размеры. Смена слова вызывает invalidate только области слова; Paint и геометрия переиспользуются. Таймер следующего слова запускается после onDraw текущего, устаревшие подтверждения игнорируются. Если onDraw не поступает три секунды, чтение останавливается на текущем индексе. Это подтверждение программной отрисовки Android, а не завершения физического обновления E-Ink. Драйвер может расширять запрошенную область обновления.

BOOX-сборка ищет методы прошивки во время выполнения. Автоматический A2 доступен только при наличии включения, выключения и запроса состояния. Если быстрый режим уже включён пользователем, приложение его не выключает. Включённый приложением режим восстанавливается при паузе/уходе из приложения. Очистка доступна только при наличии команды; отсутствие API не мешает обычному чтению. Настройка очистки на паузе по умолчанию выключена. Прошивка и системные файлы не изменяются.

Перенесены чтение EPUB/FB2/TXT/HTML/Markdown, текст из JSON-паков, библиотека, позиция, главы EPUB, закладки, контекст на паузе, аппаратные кнопки, скорость, умные паузы, шрифты и стили фокуса. Импорт и разбор идут в рабочем потоке. Текст сохраняется один раз, позиция — отдельным маленьким атомарным JSON-файлом. Есть системный выбор файла и собственный просмотр папок для старых BOOX. Библиотеку WebView нужно импортировать заново. Переводы, интервальные карточки и слоговая разбивка из веб-версии в этот нативный выпуск не перенесены; длинное слово уменьшается до ширины поля и сохраняется целиком.

Сборка обеих версий: `npm run build:apk`. Исходники: `android/native/`; сборщик: `tools/build_native_apk.js`. Работающий старый APK сохранён как `dist/FastRead-1.2.apk`.

До просьбы прекратить дополнительные тесты выполнены проверки нативного токенизатора, всех 71 слова инструкции, таймера с подтверждением onDraw, задержек/паузы/перемотки, реального EPUB и FB2/windows-1251. Оба APK скомпилированы и подписаны; подтверждено отсутствие WebView и HTML, а в универсальном APK — команд ONYX. На Android-устройстве/эмуляторе UI и физическое обновление экрана ещё не проверялись.
