<p align="center">
  <b>FastRead (Universal Android Edition)</b> — нативное приложение скорочтения методом RSVP для смартфонов и планшетов на Android.<br>
  Слова выводятся по одному в центре экрана с фиксацией взгляда на опорной букве (ORP). Глазам не нужно двигаться по строкам — текст идёт навстречу взгляду.

## 🚀 Сильные стороны универсальной версии

* **Нативная отрисовка на Canvas**: Плавное, чёткое и стабильное отображение слов на скоростях от 50 до 1500+ слов в минуту без лагов, пропусков и дерганий на экранах с любой частотой обновления (60 Гц, 90 Гц, 120 Гц).
* **Синхронизированный таймер (PlaybackClock)**: Каждое следующее слово появляется только после подтверждения физической отрисовки текущего в буфере экрана.
* **Широкая совместимость**: Поддержка абсолютно любых смартфонов и планшетов от Android 4.4 KitKat до современных версий Android 14 и 15.
* **Чтение книг офлайн**: Мгновенный разбор файлов популярных форматов **EPUB**, **FB2** (включая кодировку Windows-1251), **TXT**, **Markdown**, **HTML** без конвертации и ожидания.
* **Интерактивный контекст книги на паузе**: При остановке чтения открывается аккуратный блок с окружающим абзацем текста. Тапните по любому слову, чтобы мгновенно продолжить чтение с него.
* **Фокусная точка (ORP) и стилизация**: Настройка позиции опорной буквы и визуального стиля (прямоугольная рамка, инверсия, маркеры-стрелки, подчёркивание).
* **Умные паузы**: Автоматические микропаузы на запятых, точках, тире и длинных словах для максимально комфортного и естественного восприятия текста.
* **Главы, закладки и прогресс**: Быстрый переход по главам книги, сохранение закладок `★`, расчёт времени чтения до конца главы в реальном времени.
* **Ультралёгкий вес и скорость**: Размер APK всего **~49 КБ**, мгновенный запуск, нулевое потребление батареи в фоновом режиме.

## 📱 Интерфейс читалки

```
+-------------------------------------------------------------------------+
| [■] FastRead                   [ Книги ]   [ + Книга ]   [ Настройки ]  |
+-------------------------------------------------------------------------+
| 📖 Пикник на обочине  •  1. Рэдрик Шухарт, 23 года...                  |
+-------------------------------------------------------------------------+
|                                                                         |
|                                    |                                    |
|                              выдел[е]нную                               |
|                                    |                                    |
|                                                                         |
|            Тап: слева −10 · центр старт / пауза · справа +10            |
+-------------------------------------------------------------------------+
| 11 / 71      ━━━●━━━━━━━━━━━━━━━|━━━━━━━━━━━━━━|━━━━━━━          ≈ 14 с |
+-------------------------------------------------------------------------+
| [★]  [−] 300 сл/м [+]      [−10]  [‹]  [   ▶   ]  [›]  [+10]            |
+-------------------------------------------------------------------------+
```

* **Тап по экрану**: по центру — старт / пауза; у левого края — назад на 10 слов; у правого края — вперёд на 10 слов.
* **Кнопки управления**: плавная регулировка скорости с шагом 25 сл/мин, пошаговая перемотка на 1 слово, закладки `★`.
* **Оглавление**: нажатие на строку книги/главы открывает интерактивное оглавление.
* **Настройки**: скорость чтения, размер шрифта, шрифты (Georgia / Serif, Roboto / Sans, Monospace), стили фокуса, тёмная тема, клавиши громкости.
