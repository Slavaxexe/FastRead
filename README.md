## 📖 Особенности реализации (v1.2)

Слова появляются по одному, строго центрируясь на **опорной букве (ORP)**. Глазам не нужно совершать саккадические движения по строкам текста — книга сама идёт навстречу взгляду.

<table>
<tr>
<td width="55%" valign="top">
  <h3>⚡ Оптимизации E-Ink экрана</h3>
  <ul>
    <li><b>100% контраст без мерцания</b>: чистый чёрно-белый интерфейс без полупрозрачных затуханий и CSS-анимаций, вызывающих артефакты E-Ink матриц.</li>
    <li><b>Чёткий маркер фокуса</b>: опорная буква выделяется контрастной рамкой или жирным начертанием, различимым даже в быстрых режимах A2/Speed.</li>
    <li><b>Стабильный таймер (Engine 1.2)</b>: устранены пропуски слов на слабых процессорах (Rockchip RK3128). Выдержка каждого токена гарантируется без проглатывания кадров.</li>
    <li><b>Сниженная нагрузка на CPU</b>: обновление окружающих счётчиков прогресса ограничено интервалом 750 мс во время непрерывного чтения.</li>
  </ul>

    <li><b>Умные вкрапления (Weaving)</b>: постепенное замещение русских слов английскими с регулируемой плотностью.</li>

## 📱 Архитектура Android WebView

Версия скомпонована как сверхлегковесное гибридное приложение, совмещающее скорость нативного кода и гибкость веб-технологий:

```
┌──────────────────────────────────────────────────────────────┐
│             Android Shell (minSdk 19 / Java 8)               │
│  MainActivity.java · AndroidManifest.xml · NativeBridge      │
│  ┌────────────────────────────────────────────────────────┐  │
│  │               WebView (Chromium 30+)                   │  │
│  │  ┌──────────────────────────────────────────────────┐  │  │
│  │  │ assets/index.html (Автономный бандл ES5)         │  │  │
│  │  │ ├─ Polyfills (Promise, TextDecoder, setImmediate)│  │  │
│  │  │ ├─ JSZip 3.10.2 (Встроенный офлайн-парсер EPUB)  │  │  │
│  │  │ ├─ Core RSVP Engine (Токенизация, ORP, тайминг)  │  │  │
│  │  │ └─ Eink CSS (Монохром, геометрия, тач-зоны)      │  │  │
│  │  └──────────────────────────────────────────────────┘  │  │
│  └────────────────────────────────────────────────────────┘  │
│  ▲                                                           │
│  └─ NativeBridge: чтение файлов с SD-карты, Base64-потоки    │
└──────────────────────────────────────────────────────────────┘
```

1. **NativeBridge**:
   * Прямой доступ к файлам книги во внутренней памяти и на SD-карте без ограничений современных версий WebView.
   * Чтение больших файлов (`.epub`, `.fb2`, `.txt`, `.md`, `.json`) через эффективный потоковый буфер с передачей данных в JavaScript через Base64.
2. **Ассоциация файлов в системе**:
   * Приложение зарегистрировано в `AndroidManifest.xml` для файлов `.epub`, `.fb2`, `.txt`, `.md`, `.json`.
   * Книги можно открывать напрямую из штатного диспетчера файлов BOOX или через системное меню *«Открыть с помощью FastRead»*.
3. **Аппаратные клавиши**:
   * Перехват аппаратных кнопок листания на чехле-обложке и качелек громкости (`KEYCODE_PAGE_UP`, `KEYCODE_PAGE_DOWN`, `KEYCODE_VOLUME_UP`, `KEYCODE_VOLUME_DOWN`) с трансляцией в события перемотки слов.
4. **Режим полного погружения**:
   * Скрытие навигационных панелей и статус-бара Android (`View.SYSTEM_UI_FLAG_IMMERSIVE_STICKY`).
5. **Совместимость с ES5**:
   * Весь JavaScript транспилируется через Babel под старый движок Chromium 30 (Android 4.4 KitKat).
   * Встроены полифилы `Promise`, `Object.assign`, `replaceChildren` и замена регулярных выражений Unicode `\p{L}` на диапазоны символов.

## 🎮 Управление

### Сенсорные зоны экрана (Stage)
Экран разделен на 3 удобные зоны для чтения одной рукой:

```
┌─────────────────┬───────────────────┬─────────────────┐
│                 │                   │                 │
│      Тап        │        Тап        │       Тап       │
│     СЛЕВА       │      ЦЕНТР        │      СПРАВА     │
│                 │                   │                 │
│   −10 слов      │   Старт / Пауза   │    +10 слов     │
│                 │                   │                 │
└─────────────────┴───────────────────┴─────────────────┘
```

### Аппаратные кнопки и клавиатура
* **Кнопки листания книги / чехла**: назад / вперёд по тексту.
* <kbd>Пробел</kbd> — Старт / Пауза.
* <kbd>←</kbd> / <kbd>→</kbd> — шаг на 1 слово назад / вперёд (с зажатым <kbd>Shift</kbd> — на 10 слов).
* <kbd>[</kbd> / <kbd>]</kbd> — переход на предложение назад / вперёд.
* <kbd>↑</kbd> / <kbd>↓</kbd> — регулировка скорости чтения (WPM).
* <kbd>D</kbd> — добавить текущее слово в колоду «Не знаю».
* <kbd>L</kbd> — открыть библиотеку книг.
* <kbd>M</kbd> — смена двуязычного режима.
* <kbd>N</kbd> — вставить новый текст из буфера обмена.

## 📦 Готовые файлы сборки (v1.2)

В репозитории подготовлены протестированные бинарные файлы:

* **[`dist/FastRead-1.2.apk`](dist/FastRead-1.2.apk)** (также доступен как `dist/FastRead.apk`) — готовый к установке установочный пакет Android (~92 КБ). Совместим с Android 4.4+.
* **[`dist/index.html`](dist/index.html)** — полностью автономный однофайловый HTML-бандл (278 КБ). Может открываться в любом браузере на компьютере, планшете или телефоне (PWA).

### Установка на Onyx BOOX:
1. Подключите читалку к компьютеру по USB (или передайте файл через BooxDrop / браузер).
2. Скопируйте `dist/FastRead-1.2.apk` в память устройства (например, в папку `Download`).
3. В диспетчере файлов BOOX нажмите на файл и подтвердите установку.

## 🛠️ Сборка и тестирование

Для сборки проекта не требуется Android Studio — используются легковесные утилиты сборки:

```bash
# 1. Установка зависимостей сборщика
npm install

# 2. Сборка автономного веб-бандла (dist/index.html)
npm run build

# 3. Компиляция и подпись WebView APK (dist/FastRead.apk)
npm run build:web-apk

# 4. Запуск автоматических тестов (совместимость ES5, парсеры, тайминг)
npm test
```

## 📚 Поддерживаемые форматы

| Формат | Особенности поддержки в FastRead |
|---|---|
| **.epub** | Распаковка архива на лету через встроенный `JSZip`, чтение глав, сохранение закладок |
| **.fb2** | Парсинг XML, автоматическое определение кодировок UTF-8 и Windows-1251 |
| **.txt** / **.md** | Мгновенный разбор текстовых файлов произвольного размера |
| **.json** | Размеченные двуязычные паки с переводами и морфологией |
