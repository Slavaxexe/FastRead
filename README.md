## 🚀 Сильные стороны универсальной версии

* **Цветовая палитра Германа Эделькина**: Современная тёмная тема (`#121315`), тёплая книжная бумага (`#f5f2ec`) и глубокий AMOLED-режим (`#000000`).
* **Яркая опорная буква и направляющие**: Опорная буква подсвечивается акцентным красным цветом (`#ff4b4e` / `#de2328`), а верхняя и нижняя направляющие с центральными засечками помогают глазу удерживать идеальный фокус.
* **Нативная отрисовка на Canvas (60 / 90 / 120 Гц)**: Мгновенное и плавное воспроизведение слов на скоростях от 50 до 1500+ сл/мин без задержек и пропусков кадров.
* **Эргономичный двухрядный пульт управления для смартфонов**:
  - Верхний ряд: кнопка закладок `🔖` и капсула регулировки скорости `[ − 350 сл/м + ]`.
  - Нижний ряд: крупная 56dp круглая кнопка пуска `▶ / ❚❚` и удобные кнопки шага по словам (`‹`, `›`) и прыжков на 10 слов (`−10`, `+10`).
* **Погружение в чтение (Auto-Dimming)**: При запуске чтения шапка и элементы управления плавно затухают, оставляя вас один на один с текстом. При паузе или тапе интерфейс мгновенно возвращается.
* **Типографика контекста на паузе**:
  - Двусторонняя выключка (полное выравнивание строк по ширине) без рваных краёв.
  - Оформление эпиграфов с вертикальной чертой, курсивом и подписью автора справа.
  - Выделение автора и названия книги в начале по стилю глав.
  - Мгновенный переход к любому слову по тапу.
* **Чтение любых книг офлайн**: Поддержка форматов **EPUB**, **FB2** (включая кодировку Windows-1251), **ZIP-архивов книг** (из Telegram и браузеров), **TXT**, **Markdown**, **HTML**.
* **Ультралёгкий вес и автономность**: APK весит всего **~49 КБ**, не тратит батарею в фоне и запускается мгновенно.

## 📱 Интерфейс читалки

```
+-------------------------------------------------------------------------+
| • FastRead                      [ Книги ]   [ + Книга ]   [ ⚙ ]         |
+-------------------------------------------------------------------------+
| 📖 Пикник на обочине  •  1. Рэдрик Шухарт, 23 года...                   |
+-------------------------------------------------------------------------+
|                                    |                                    |
|                              выдел[е]нную                               |
|                                    |                                    |
+-------------------------------------------------------------------------+
| 11 / 71      ━━━━━━━━━●━━━━━━━━━|━━━━━━━━━━━━━━|━━━━━━━          ≈ 14 с |
+-------------------------------------------------------------------------+
|     [ 🔖 ]                     [ −  350 сл/м  + ]                       |
|                                                                         |
|            [ −10 ]    [ ‹ ]    ((   ▶   ))    [ › ]    [ +10 ]          |
+-------------------------------------------------------------------------+
```

* **Тап по экрану**: по центру — старт / пауза; у левого края — назад на 10 слов; у правого края — вперёд на 10 слов.
* **Оглавление**: нажатие на строку книги/главы открывает интерактивное оглавление.
* **Настройки**: темы (Тёмная, Тёплая бумага, AMOLED), скорость чтения, размер шрифта слова и текста на паузе, умные паузы на знаках препинания.
