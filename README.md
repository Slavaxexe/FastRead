## ⚡ Сильные стороны версии для Onyx BOOX

* **Аппаратный A2-режим экрана**: Приложение напрямую активирует скоростной режим перерисовки дисплея электронных чернил (A2 Fast Animation). Никаких задержек и размытия даже при скорости 500–1000+ слов в минуту.
* **Глубокая очистка экрана (GC Refresh)**: Полное аппаратное устранение остаточных артефактов (ghosting) при паузе — экран всегда остаётся кристально чистым.
* **Сверхконтрастный режим MonoInk**: Отрисовка глифов шрифта в чистом чёрно-белом формате без сглаживания полутонами, обеспечивая максимальную резкость и лёгкость чтения при любом освещении.
* **Полная поддержка физических кнопок**: Управление чтением боковыми кнопками листания книги и чехла, клавишами громкости или пультом (пауза, перемотка по 10 слов, плавная регулировка скорости).
* **Встроенный файловый проводник ридера**: Мгновенный доступ к книгам во внутренней памяти (`/sdcard/Books`, `/sdcard/Download`) и на подключённых SD-картах.
* **Чтение книг офлайн**: Поддержка форматов **EPUB**, **FB2** (включая кодировку Windows-1251), **TXT**, **ZIP-архивов книг**, **Markdown**, **HTML**.
* **Типографика контекста на паузе**: Полное выравнивание текста по ширине (двусторонняя выключка строк), оформление эпиграфов с вертикальной чертой и цитатой, выделение названия и автора книги, мгновенный переход по тапу на любое слово.
* **Умная навигация**: Главы, закладки в один клик, точный индикатор прогресса и расчёт времени до конца главы в реальном времени.
* **Крошечный размер и автономность**: APK весит всего **~56 КБ**, потребляет минимум оперативной памяти и работает часами, сохраняя заряд аккумулятора ридера.

## 📥 Быстрая установка

1. Скачайте APK по кнопке выше или по прямой ссылке: **[FastRead.apk](https://github.com/Slavaxexe/FastRead/raw/boox/dist/FastRead.apk)**.
2. Скопируйте файл на ридер Onyx BOOX или откройте через встроенный браузер читалки.
3. Запустите установку. Приложение работает на Onyx OS (Android 4.4 KitKat и выше).

## 📱 Интерфейс читалки

```
+-------------------------------------------------------------------------+
| [■] FastRead                   [ Книги ]   [ + Книга ]   [ Настройки ]  |
+-------------------------------------------------------------------------+
| 📖 Пикник на обочине  •  1. Рэдрик Шухарт, 23 года...                  |
+-------------------------------------------------------------------------+
|                                                                         |
|                                    |                                    |
|                              выдел[е]нную                               |
|                                    |                                    |
|                                                                         |
|            Тап: слева −10 · центр старт / пауза · справа +10            |
+-------------------------------------------------------------------------+
| 11 / 71      ━━━●━━━━━━━━━━━━━━━|━━━━━━━━━━━━━━|━━━━━━━          ≈ 14 с |
+-------------------------------------------------------------------------+
| [★]  [−] 300 сл/м [+]      [−10]  [‹]  [   ▶   ]  [›]  [+10]            |
+-------------------------------------------------------------------------+
```

* **Тап по экрану**: по центру — старт / пауза; у левого края — назад на 10 слов; у правого края — вперёд на 10 слов.
* **Кнопки управления**: регулировка скорости с шагом 25 сл/мин, пошаговая перемотка на 1 слово, закладки `★`.
* **Оглавление**: нажатие на строку книги/главы открывает список глав для быстрого перехода.
* **Настройки**: размер шрифта, задержки на знаках препинания, стиль рамки опорной буквы, тёмная тема, очистка экрана.
