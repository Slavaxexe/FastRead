## 🚀 Нативная версия FastRead для Android (v2.0)

Полностью переписанное нативное приложение на базе Android SDK (без WebView, без Chromium и без DOM-накладных расходов).

### ✨ Ключевые преимущества

* **Чистый Android Canvas**: отрисовка напрямую в буфер видеопамяти через `android.graphics.Canvas` и `Paint`. Каждый кадр аппаратно заливает область слова, полностью исключая фантомные артефакты и наложение букв.
* **Синхронизированный таймер (`PlaybackClock`)**: следующее слово запускается только после физического подтверждения отрисовки текущего (`onDrawn`). Чтение не убегает вперёд и не пропускает слова при высокой нагрузке.
* **Универсальность**: один и тот же APK-файл работает на смартфонах/планшетах (Android 4.4 KitKat — Android 15) на частоте 60/120 Гц и на читалках Onyx BOOX с автоматическим переключением в скоростной E-Ink режим A2.
* **Мгновенный парсинг книг**:
  * **EPUB**: распаковка и разбор через нативный `java.util.zip.ZipFile` и потоковый SAX XML.
  * **FB2**: обработка через встроенный Android `XmlPullParser` с автоматическим определением кодировок (UTF-8, Windows-1251).
  * **TXT / MD / HTML / JSON**: потоковое чтение до 700 000 слов без зависаний UI.
* **Лёгкость и автономность**: размер APK всего **~48 КБ**, потребление оперативной памяти — менее 15 МБ (в 5–8 раз меньше старого WebView).

## 📱 Интерфейс и возможности

```
+-------------------------------------------------------------------------+
| [■] FastRead                   [ Книги ]   [ + Книга ]   [ Настройки ]  |
+-------------------------------------------------------------------------+
| 📖 Пикник на обочине  •  1. Рэдрик Шухарт, 23 года...                  |
+-------------------------------------------------------------------------+
|                                                                         |
|                                    |                                    |
|                              выдел[е]нную                               |
|                                    |                                    |
|                                                                         |
|            Тап: слева −10 · центр старт / пауза · справа +10            |
+-------------------------------------------------------------------------+
| 11 / 71      ━━━●━━━━━━━━━━━━━━━|━━━━━━━━━━━━━━|━━━━━━━          ≈ 14 с |
+-------------------------------------------------------------------------+
| [★]  [−] 300 сл/м [+]      [−10]  [‹]  [   ▶   ]  [›]  [+10]            |
+-------------------------------------------------------------------------+
```

1. **Верхняя панель**:
   * Логотип `■ FastRead`.
   * Кнопки «Книги» (библиотека с процентом прочитанного и историей), «+ Книга» (системный выбор или встроенный проводник памяти), «Настройки».
2. **Панель книги и глав**:
   * Индикатор открытой книги и текущей главы. Тап открывает интерактивное оглавление с переходом к любой главе.
3. **Поле чтения (RSVP Stage)**:
   * Направляющие линии с центральными засечками фокуса.
   * Опорная буква (ORP) выделяется прямоугольной рамкой, инверсией, стрелками или подчёркиванием.
   * Шрифты: с засечками (Georgia / Serif), без засечек (Roboto / Sans), моноширинный.
4. **Контекст книги на паузе**:
   * При остановке чтения открывается стилизованный блок с окружающим текстом, абзацными отступами и рамкой вокруг текущего слова.
   * Нажатие на любое слово мгновенно перемещает чтение на эту позицию.
5. **Индикатор прогресса и шкала**:
   * Счётчик прочитанных слов и общее количество.
   * Ползунок с физическими засечками начала глав и закладок.
   * Расчёт оставшегося времени до конца книги/главы в реальном времени.
6. **Единый ряд элементов управления**:
   * Добавление/просмотр закладок `★`.
   * Регулировка скорости (`−` / `+` с шагом 25 сл/мин).
   * Перемотка на 1 слово назад/вперёд (`‹` / `›`) и на 10 слов (`−10` / `+10`).
   * Крупная контрастная кнопка Старт/Пауза (`▶` / `❚❚`).

## ⚡ Оптимизация для Onyx BOOX

Приложение содержит интеллектуальный контроллер экрана (`ScreenController`), использующий безопасную рефлексию прошивок Onyx OS (Android 4.4 / Rockchip RK3128 / Carta E-Ink):

* Автоматическое включение режима **A2 (Fast Animation Mode)** во время непрерывного чтения.
* Возможность аппаратной полной очистки экрана (**GC Full Refresh**) при постановке на паузу.
* Полная поддержка аппаратных кнопок листания и громкости на корпусе и фирменных чехлах ридеров.

## 🛠️ Сборка проекта

Для сборки нативного APK не требуется тяжеловесный Android Studio или Gradle — процесс скомпонован через легкие скрипты:

```bash
# 1. Сборка нативного Android APK (dist/FastRead.apk)
node tools/build_native_apk.js

# 2. Запуск нативных тестов (токенизатор, таймер, EPUB, FB2, Unicode)
node tools/test_native.js

# 3. Сборка веб-версии (dist/index.html)
node tools/build.js
```

Готовый файл:
```
dist/FastRead.apk (48.5 КБ) — универсальный APK для установки на устройства
```
